# Phone banners — AI recomposed (not cropped)

These `/images/mobile/…` assets are **vertical recompositions** of the desktop banners:

- Full jewellery product kept in frame
- Same nature-inspired scenery / lighting / mood
- Portrait 9:16 canvas (phone), not a hard crop of the landscape file

Do **not** overwrite with `npm run banners:mobile -- --force` (that is crop-only fallback for missing files).
