1. Welcome & how to use this guide

This is your private house console. From here you control what appears on the Velvet Shell website: jewellery products, homepage selections, discounts, customer orders, and soft content like looks, blogs, and testimonials.

How to learn fastest

Read sections 2–5 first (login, navigation, dashboard, products). Those are what you will use every day. Then learn orders (section 9). Use the rest as a reference when you need homepage, discounts, or content.

Two kinds of pages

  • Live commerce pages (Products, Categories, Homepage strips, Discounts, Orders, Customers, Dashboard) — saved to the house database and reflected on the live website.
  • Content tools (Shop by look, Blogs, Testimonials) — managed inside the admin for storefront content blocks. Prefer editing them from the same computer/browser you normally use for admin work.

2. Signing in & signing out

Open the admin

Go to your admin web address (the private console URL shared with you). You will see a screen titled Admin access.

Sign in

  1. Enter your admin email.
  2. Enter your password.
  3. Click Enter console.
  4. Wait for “Signing in…” — then you land on the Dashboard.

If login fails

  • Check Caps Lock and that you are using the admin account (not a customer account).
  • If you see “Too many attempts. Try again later.” — wait a few minutes and try again.
  • Ask your technical contact to reset access if the password no longer works.

Sign out

  1. Open the left sidebar.
  2. At the bottom, click Log out.
  3. You return to the login screen. Always log out on shared computers.

3. Sidebar, layout & navigation

Every page shares the same shell: a dark left sidebar and a light work area.

Collapse / expand the sidebar (desktop)

  1. When the sidebar is open, click the × (close) icon at the top-right of the sidebar to collapse it to icons only — more room for tables and forms.
  2. When collapsed, click the hamburger (three lines) at the top of the rail to expand again.
  3. The console remembers your choice for next time.

On a phone or small laptop

  1. Tap the menu button in the top bar to open the sidebar.
  2. Choose a page — the menu closes automatically.
  3. Tap × or the dimmed background to close without navigating.

Orders badge

Orders in the sidebar may show a small number (or gold dot when collapsed). Treat it as a reminder to check the Orders page for work waiting on you.

4. Dashboard

Your morning overview. Most numbers are clickable and take you straight into the right filtered list.

What you will see

  • Live products — active on the website
  • Draft products — saved but not live yet
  • Low stock — stock of 3 or fewer
  • Out of stock — needs attention
  • Missing images — products without a proper hero image
  • Orders / open orders — fulfilment workload
  • Revenue — this month / this year / total confirmed
  • Active discounts
  • Low stock list and recent orders at the bottom

How to use it

  1. Open Dashboard after login.
  2. Scan for red flags: low stock, out of stock, missing images, open orders.
  3. Click a card (for example Draft products) to jump into Products already filtered.
  4. Use Recent orders → View all to start fulfilment.

5. Products — the heart of the catalogue

Products are saved as families. One family can have one colour, or several colour variants (Silver / Gold / Pink…) each with its own photos, price, and stock.

5.1 Product list

Go to Products in the sidebar.

  • See every family: thumbnail, name, slug, price, category, collection, colour count, status, stock.
  • Use filters: Search, Category, Collection, Status (Active / Draft), Stock (Low / Out / In).
  • Click a product name/row to edit it.
  • Click Add product to create a new piece.

Status meanings

  • Active — visible on the live website (when published correctly).
  • Draft — saved in admin, not shown as a live listing.

5.2 Add a new product (full walkthrough)

  1. Click Add product.
  2. Basics
    • Enter the Name (required). The slug (web address piece) is created automatically from the name.
    • Optional Badge (for example “New · Floral”).
    • Choose Category and Collection.
    • Set Status: keep as Draft while you finish photos; switch to Active when ready to sell.
  3. Shipping — edit the intro text, India ETA, and notes if your atelier timing changed. Defaults are already sensible for India.
  4. Recommendations — optionally tick other products for “You may also like” (available once more products exist).
  5. Customization (optional but powerful)
    • Tick Customization available? if the shopper must give you extra details.
    • Write a clear prompt, for example: Specify the dangles length.
    • Choose input type: Text, Number, or Long text.
    • Add a placeholder hint if helpful (e.g. “e.g. 2.5 inches”).
    • Tick Required if they must answer before adding to bag.
    • Use + Add prompt for more questions (initials, message, chain length…).
  6. Colour variants
    • If the piece exists in only one finish, leave “color variants” off (single Default colour).
    • If it exists in Silver and Gold (etc.), tick Does this product have color variants?
    • Add colours with presets (+ Silver, + Gold…) or + Custom color.
    • Name each colour, pick a swatch, and mark one as Primary listing color.
    • Optional: Import details from another colour to copy price/copy/stock — photos are not copied (upload each colour’s own photos).
  7. Details for the active colour
    • Set Price (INR) and Stock.
    • Confirm Material (often auto-suggested from the colour name).
    • Add size pills (e.g. Adjustable, 16", 18"). Press Enter or Add pill. If you leave sizes empty, the site shows “One size”.
    • Fill Description, The piece (story), Care, and Features (one feature per line).
    • Optional review rating / count if you want to display social proof.
  8. Hero & gallery images
    • Upload a Hero image for the active colour (direct file upload — not a URL).
    • Upload one or more Gallery images. Wait until uploading finishes.
    • Switch colour tabs and upload that colour’s photos separately so finishes never mix.
  9. Click Save product. Wait for “Saving product…” to finish.
  10. You are taken to the product’s edit page. Review once, then set Status to Active when you want it live.

5.3 Edit an existing product

  1. Products list → click the product.
  2. Change any section (price, stock, photos, customization prompts, shipping…).
  3. Click Save product.

5.4 Delete a product

  1. Open the product edit page.
  2. Click Delete (top area).
  3. Confirm when asked — this removes the whole family and all its colour variants.

Careful

Deletion cannot be undone from the admin. Prefer setting Status to Draft if you only want to hide a piece temporarily.

5.5 Customization answers (what the customer sees)

When customization is enabled, the product page on the website shows your prompts. The shopper types text or a number. Their answers appear in:

  • Their bag / cart / checkout
  • The order detail in admin (highlighted as Customization)

Always write prompts in plain language the customer will understand.

6. Categories

Categories power the product form and storefront filters (Earrings, Rings, Necklaces…).

  1. Open Categories.
  2. Enter a Name (required).
  3. Slug is optional — leave blank to auto-create from the name.
  4. Optional Line (short description).
  5. Click Save category.

Updating a category

There is no separate “edit” button on each row. To update, save again using the same slug (or the same name so the slug matches). There is no delete button — ask your technical contact if a category must be removed from the database.

7. Homepage: Festive Edit & Best sellers

These two pages control curated product strips on the website homepage.

Festive Edit

Seasonal / festive selection strip. Open Festive Edit.

Best sellers

“Best of Velvet Shell” strip. Open Best sellers.

How to curate either strip

  1. Edit the section copy if needed: Eyebrow, Title, Supporting line.
  2. Use Search / Category / Collection filters to find products.
  3. Tick products in the table (or use Select visible).
  4. In the Selected order list, use Up / Down to set homepage order, or Remove.
  5. Click Save changes.

Order matters

The order of the selected list is the order customers see on the homepage.

8. Discounts & promo codes

Open Discounts to manage promo codes and bulk-buy tiers.

List page

  • See usage stats: times used, sales revenue, discount given.
  • Filter tabs: Active / Past / All.
  • New promo code or Bulk offer to create.
  • Click a row to edit.

Create a promo code

  1. Click New promo code.
  2. Enter an internal Name.
  3. Enter a Code shoppers will type (or click Generate). Codes are stored in capitals.
  4. Choose Percentage or Flat amount (₹) and set the value.
  5. Optional: minimum order, max total uses, max uses per customer.
  6. Choose where it applies: entire catalogue, categories, collections, or selected products.
  7. Set start/end dates and status (Active / Paused / Draft).
  8. Save.

Create a bulk-buy offer

  1. Click Bulk offer (or create discount → Bulk buy tiers).
  2. Add tiers such as “Buy 2 → 10% off”, “Buy 3 → ₹500 off”.
  3. The highest matching quantity wins at checkout.
  4. Set scope, schedule, status → Save.

Delete a discount

Open the discount → Delete → confirm.

9. Orders & fulfilment

This is how you process every paid order from the website.

Orders list

  1. Open Orders.
  2. Use status chips: All, Pending, Accepted, Packed, Dispatched, Delivered, Cancelled.
  3. Search by order number, email, or customer name.
  4. Look for Custom notes under Pieces — that order has customization answers.
  5. Click Open (or the order number) for the full detail.

Recommended fulfilment flow

Pending→ Accepted→ Packed→ Dispatched→ Delivered
StatusMeaning for the atelier
PendingNew / awaiting your attention
AcceptedPayment confirmed — you have taken the order
PackedPiece prepared / packed for courier
DispatchedHanded to courier / shipped
DeliveredCustomer received the piece
CancelledOrder stopped / cancelled

Order detail page — what to check

  • Customer — name, email, phone
  • Ship to — full address
  • Payment — Razorpay reference
  • Line items — product photo, name, metal, size, quantity, price
  • Customization — each prompt and the customer’s answer (read carefully before making the piece)
  • Totals — subtotal, shipping, total

Update status

  1. Open the order.
  2. Use the Fulfilment status dropdown.
  3. Choose the new status — it saves immediately (you should see “Saved”).
  4. The progress strip at the top updates for the main flow.

Good practice

Move statuses in order (Accepted → Packed → Dispatched → Delivered). Only use Cancelled when the order will not ship. There is no “delete order” button — keep the record for history.

10. Customers

Open Customers to see people connected to accounts / orders.

  1. Browse the table: name, email, phone, order count, amount spent.
  2. Click a customer to open their side panel.
  3. Review their order history (order number, status, total).

This page is view-only — you do not edit customer profiles here. Use it for outreach and order follow-up.

11. Shop by look

Create lifestyle look images with soft glowing hotspots. Shoppers tap a light to open the linked product.

  1. Open Shop by look.
  2. Edit the look title / supporting line / alt text if needed.
  3. Upload the look image (direct upload). Replacing the image clears existing hotspots — place them again.
  4. Click Mark hotspots.
  5. Click on the image where the jewellery sits → choose a product from the picker.
  6. Adjust with Change / Remove in the hotspot list.
  7. Click Save look.

Accuracy tip

The image is shown full (not cropped) so hotspot positions stay correct on the website.

12. Blogs

  1. Open Blogs.
  2. Filter All / Live / Draft.
  3. Click Add blog.
  4. Enter Title (slug auto-fills), Status, Cover image (upload), Excerpt, Body.
  5. Save blog.
  6. To edit later: open the post from the list, update fields (including Eyebrow / Published label on the edit screen), Save.

Set status to Live when the post should appear; keep Draft while writing.

13. Testimonials

  1. Open Testimonials.
  2. Click Add testimonial (or click an existing card to edit).
  3. Fill Name, Place, Piece worn, Quote.
  4. Upload a portrait image (and optional second image).
  5. Tick Active on storefront to show it; untick to hide.
  6. Save.

Hiding vs deleting

There is no delete button. Untick Active on storefront to hide a quote without removing it.

14. Uploading images (important)

Everywhere you see image fields in admin, you upload a file from your computer. You do not need to paste a web URL.

  1. Click Upload image / Upload hero / Upload gallery.
  2. Choose a file from your device.
  3. Wait for the spinner (“Uploading…”) to finish.
  4. Confirm the preview looks correct.
  5. Then click the page’s main Save button (Save product / Save look / Save blog…).

Rules of thumb

  • Prefer clear, well-lit jewellery photos.
  • Keep files reasonably sized (very large videos/images can fail; max about 40MB).
  • Never navigate away mid-upload.
  • On products with multiple colours, upload photos while that colour tab is selected.
  • If upload fails with a Cloudflare / R2 configuration message, contact your technical partner — hosting keys may need checking.

15. Everyday checklist

Morning

  • Dashboard → check open orders, low stock, missing images.
  • Orders → move Pending → Accepted for anything new and paid.

When a new piece arrives

  • Products → Add product → photos per colour → Draft → review → Active.
  • Add customization prompts if the piece needs measurements or notes.
  • Optionally add it to Festive Edit or Best sellers.

When packing / shipping

  • Open the order → read customization carefully → Pack → Dispatch → Deliver.

Weekly

  • Review discounts (pause or expire old codes).
  • Refresh testimonials / looks / blog if you have new stories.

16. Common questions & troubleshooting

I saved a product but can’t see it on the website

  • Is Status set to Active (not Draft)?
  • Hard-refresh the website or try a private browser window (cache).
  • Confirm the product has a hero image and price greater than zero.

Customer customization isn’t showing on the order

  • On the product, confirm Customization available? is ticked and prompts have labels.
  • Required prompts must be filled before add-to-bag on the website.
  • Open the order detail — answers appear in the gold-edged Customization block on each line.

Upload button does nothing / errors

  • Stay logged in.
  • Try a smaller JPG/PNG.
  • If the message mentions Cloudflare R2, ask your technical partner to verify admin upload keys.

I can’t find Collections as a menu item

Collections are chosen inside the Product form (and discount scope). There is no separate Collections page in this console.

Who to contact

For login issues, missing migration errors, or upload hosting problems, message your Velvet Shell technical partner with a screenshot of the exact error text.
